Die Karte folgt der Küche

Zwei Küchen, ein Haus

Sushi und Wok brauchen das Gegenteil voneinander: die eine Hälfte kühlt, die andere heizt. Deshalb ist auch die Karte in zwei Hälften geteilt — Sie können in einer bleiben oder wechseln.
